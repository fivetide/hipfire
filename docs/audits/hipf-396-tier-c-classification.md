# HIPF-396 tier C: classification of the 122 arch-gated default-ON flags

Working document for HIPF-451 (parent HIPF-396, audit #1130). Classification only, no code changes. Base: beta `84b8a1911`. Input: `tierC_alive.tsv` (122 flags, all still read on beta).

Status: first pass. Rows marked `[INFERENCE]` were not fully code-verified; `none found` in evidence means no introducing measurement was found in a time-boxed search (git log -S, docs/perf-checkpoints, docs/investigations, CHANGELOG, env-vars.md). gfx12 (gfx1201) and CDNA (gfx942) rows need correction by Kaden.

## Cases

1. Untested elsewhere: needs validation on the other arches.
2. Measured worse elsewhere: per-arch tuning, move into a typed table.
3. Capability proxy: gate on the capability (WMMA, FP8, dp4a, wave64), delete the env flag, keep the fallback.
4. Known broken elsewhere: bind to safe arches, link the bug.
5. Model or shape conditional: dispatch policy or model card `recommended_settings`.
6. Memory or host policy: typed config key plus `FeatureFlags` (as HIPF-430).
7. Multi-value mode: typed config key with `auto` default.
8. Unreachable arch path (CDNA): question for Kaden.
