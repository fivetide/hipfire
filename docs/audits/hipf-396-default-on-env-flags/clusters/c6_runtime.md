## Notes

- **Excluded or conditional (not in table):**
  - `HIPFIRE_QWEN35_GRAMMAR` (prompt_frame.rs:530) is ON only for `carnice` models when unset, OFF otherwise. Not a default-ON flag.
  - `HIPFIRE_DFLASH_WINDOW` (examples/dflash_spec_demo.rs:1805) is unset → draft-declared window, else Legacy. Commit b368ee643 calls it "opt-in". Not default-ON, but the draft's own declaration picks windowed. Decide case by case.
  - `HIPFIRE_MTP_MODE` and `HIPFIRE_LM_HEAD_F16` default to `auto` (config.rs:317, 286). Consumers are outside this crate's src (daemon/serve) or absent, so I could not judge what `auto` selects.
  - `HIPFIRE_DRAFT_COLLAPSE_OFF` is a kill switch described in the dflash.rs:2439 doc comment. Its read site is outside this crate.
  - `HIPFIRE_GRAPH`, `HIPFIRE_GRAPH_MOE`, `HIPFIRE_GEMMA4_GRAPH`, and `HIPFIRE_FAST_SAMPLE` are read outside this crate (hipfire-generate, hipfire-arch-gemma4). Examples set `HIPFIRE_GRAPH=0` to disable, which suggests default-ON, but I did not verify it.
- **Possible dead flag:** `HIPFIRE_DFLASH_FAST_SAMPLE` is read into `RuntimeConfig.dflash_fast_sample`, but no code under crates/ reads that field. The env var does nothing.
- **Mismatch to check:** commit 616829ae9's subject says "keep decode on RCCL (peer-direct opt-in)", but the current default in ep.rs:92 is `DecodeArMode::Canonical` (rooted peer, not RCCL). Either the commit subject is stale or the default changed later.
- **Not sized:** I did not measure OFF-path line counts for any row. Sizes need a pass per path.
- **Introduced column:** from `git log -S` first-hit (oldest). For flags that appear in several commits, a rename or refactor may hide the true origin (for example the DSPARK_Q8_* rows all point at 076318599, a refactor that renamed env vars).
