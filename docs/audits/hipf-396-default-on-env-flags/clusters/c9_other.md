## Notes

- Not a feature/perf flag: HIPFIRE_NO_REGISTRY_FETCH (network fetch) is a kill-switch but is not a kernel/path choice; included because it matches the `HIPFIRE_NO_*` pattern. Same for HIPFIRE_PINNED_XFER_DEFAULT (driver allocator tuning).
- Ambiguous, included with caveat: HIPFIRE_RAON_SHARED_FFN (default qt44 is a storage format, not clearly the "new" path). HIPFIRE_RAON_RAILGUN default Auto (mode resolved at runtime from corpus availability).
- Ambiguous, NOT included (default selects a route/storage choice with no on/off meaning, or default is OFF-equivalent): HIPFIRE_RAON_LM_HEAD (default q8f16, qt44 opt-in); HIPFIRE_MAPLE_DOWN (default `Expanded`, alternatives `atomic`/`expanded-nocombine`, crates/hipfire-arch-maple/src/forward.rs:617); HIPFIRE_FLUX_ATTN (default route per arch via rdna_compute::attention::flux_attn_route_name, crates/hipfire-arch-diffusion/src/flux_gpu.rs:191); HIPFIRE_WEIGHT_SLAB (unset means load default, DEFAULT_SLAB_MODE=Up2M in hip-bridge/src/ffi/weight_slab.rs:72, only applies when set).
- Default-OFF kill-switch-shaped names checked and excluded: HIPFIRE_NO_Q8_ROUTER and HIPFIRE_NO_SPILL (both `== "1"`, crates/hipfire-quantize/src/pipeline.rs:2616, 3277).
- Introduced-commit column is `git log -S<name> --reverse | head -1`. The `-S` pickaxe finds where the string first appears; rename-only or const-moved occurrences could hide a different earlier origin.
- Flags whose default changed after introduction (introducing commit describes the opposite default): HIPFIRE_RAON_MHC_FUSED (b11315219 "default OFF", now `true`), HIPFIRE_RAON_RAILGUN (a1a7b8832 "default off", now Auto).
- Out of scope but relevant: crates/pm-census/src/tune/ktok.rs:774-775 sets `HIPFIRE_GRAPH=0` and `HIPFIRE_NORMALIZE_PROMPT=0` for subprocesses, which implies default-ON flags read in excluded crates (not verified here). HIPFIRE_QWEN35_GRAMMAR's default lives in `crates/hipfire-runtime/src/prompt_frame.rs:528` (excluded crate), not checked.
- Not covered: the hipfire-config `developer_bool` / `developer_var` wrappers themselves (excluded crate). Scratch files c9_raw.txt and c9_src.txt were used for grep and removed.
- `hipfire-cli` main.rs and `serve/complete.rs` contain many HIPFIRE_ names, but almost all are tests, help text, or completion lists. No default-ON reads found there.
