### Notes

- **introduced** is the first commit whose diff contains the name (`git log -S`, oldest line). It is not always the commit that set the default. Several flags were opt-in or default-off at intro and flipped later: `HIPFIRE_CPU_POOL_SPIN`, `HIPFIRE_EP_COMPACT_SCRATCH`, `HIPFIRE_GFX1100_ROUTER_W64`, `HIPFIRE_QWEN4_G942_FOLD_ELEM`, `HIPFIRE_G942_BF16_WIDE`, `HIPFIRE_RAON_MHC_FUSED`, `HIPFIRE_QWEN4_EP_TAIL_BORROW`. Use `git log -S` with the flip commit for the real default history. `HIPFIRE_DUMP_HIDDEN` and `HIPFIRE_DEEPSEEK4_MOE_DETERMINISTIC` were first introduced in unrelated commits.
- **Not obsolete, per code comments:** `HIPFIRE_ROUTE_PLAN` (OFF serves route-walk tooling), `HIPFIRE_VERIFY_GRAPH` (the G0 harness requires `=0`). Also `HIPFIRE_QWEN4_EP_TAIL_BORROW`, whose intro says WIP and whose const is now default-on, should be checked against its card gates before any removal.
- **Conditional defaults:** `HIPFIRE_PAGE_EVICTION` is on only on UMA devices. `HIPFIRE_GDN_COMPACT2` and `HIPFIRE_CONV_QKNORM` are arch-gated. `HIPFIRE_Q8_PREFILL_WMMA` needs `has_wmma`. `HIPFIRE_MOE_NINEPATH` is on only on the d4 eligible shape.
- **Inverted name:** `HIPFIRE_LLOYD_MMQ_OFF` is ON by default and `=1` turns it off.
- **Excluded, default is OFF or not on/off:** `HIPFIRE_GLIMMER_SPEC_FALLBACK` (fatal unless `=1`, so fallback is off by default). `HIPFIRE_QWEN35_GRAMMAR` (on only for carnice model paths, see `hipfire-runtime/src/prompt_frame.rs:528`). `HIPFIRE_GEMMA4_EAGLE`, `HIPFIRE_EP_UNIT_DONORS`, `HIPFIRE_EP_UNIT_LANE_GROWTH`, `HIPFIRE_EP_CHUNK_AUTOFIT`, `HIPFIRE_FLASH_PREFILL`, `HIPFIRE_EMIT_TOKEN_IDS`, `HIPFIRE_CPU_SPLIT_TRACE`, `HIPFIRE_CPU_EXEC_TRACE`, `HIPFIRE_DFLASH_CHAT` (opt-in `=1` or `is_ok` trace/debug flags).
- **Excluded, tri-state or numeric:** `HIPFIRE_LANE_ADMIT_COALESCE_MS` (window in ms; default 2), `HIPFIRE_KV_V`, `HIPFIRE_SPEC_RETIRE`, `HIPFIRE_CONV_QKNORM_SHAPE` (shape selector, default b256), `HIPFIRE_DEEPSEEK4_MOE_LLOYD_4W` (auto when unset), `HIPFIRE_THINK_CONTINUATION` (string override), `HIPFIRE_FA_PERTOKEN_MIN_CTX`, `HIPFIRE_CPU_EXPERT_THREADS`.
