## Notes

1. Scope coverage: minimax, lfm2moe, lfm2-vl, and ds4-parent have no default-ON env flags. Their env reads (HIPFIRE_MINIMAX_GRAPH, HIPFIRE_LFM2_GRAPH, HIPFIRE_LFM2_CAPTURE_POSTMIXER, HIPFIRE_MINIMAX_ENABLE_DOWN_AWQ, HIPFIRE_LFM2_LOAD_TRACE, etc.) all default OFF. lfm2-vl has no env reads.
2. mq2r short-circuit: several rows (E8_WO_GROUPED, E8_U4, E8_PREFILL_B2/B4, HC_PINGPONG, HC_FINALIZE_FUSED, HC_CONTROL_FINALIZE_FUSED) are written as `mq2r || env`. On the production MQ2R artifact the env var is never consulted, so for that artifact the flag cannot be turned off. Those rows are default ON for mq2r and only observable for non-mq2r artifacts.
3. Excluded as numeric tunables (not on/off): HIPFIRE_DEEPSEEK4_ROUTE_SCALE, _POST_SCALE, _PP_BATCH, _INDEXER_TOPK_TWOSTAGE_MIN (default 1024), _DSPARK_CONF_THRESHOLD, _DSPARK_VERIFY_GRAPH_BATCH, HIPFIRE_PARENT_ROUTE_SCALE, HIPFIRE_DEEPSEEK4_PARENT_POST_SCALE, HIPFIRE_DPM_WARMUP_SECS (example). E8_BATCHED_GEMV is kept as a mode row because 0 means off.
4. Excluded as paths or other non-flag env: HIPFIRE_ROCM_PATH, HIPFIRE_DEEPSEEK4_MODEL, _MTP_ADDON, _REAP_KEEPMAP, _PARENT_MODEL, _REAP_PLAN, DS4_DENSE_ACT_DIR, DSPARK_FIXTURE (test-only).
5. Excluded as default OFF: the remaining HIPFIRE_DEEPSEEK4_* DUMP/TRACE/DEBUG/BISECT/STAGE_NORM/LAYER_NORM/SKIP_FFN/SKIP_HEAD flags, GFX942_COMPRESSOR_GATE, GFX942_HC_FINALIZE_FUSED, GFX942_FFN_OVERLAP, GFX1201_INDEXER_ROPE_HEADS, FUSED_ROUTE_ACT, RETAINED_EMBEDDING, REDLINE_FFN_SPLIT, HC_CONTROL_RSQRT_ONCE, HC_FINALIZE_INPUT_MAP, QNORM_ROTATE_FUSED, WO_MULTIROW, ATTN_PER_POS, DSPARK_VERIFY_*, and the MINIMAX and LFM2 flags listed in note 1.
