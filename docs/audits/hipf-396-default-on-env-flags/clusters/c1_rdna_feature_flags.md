## Notes

- Scope: 160 env vars read in feature_flags.rs with a default-ON effect. Counted: `unwrap_or(true)`, arch-conditional `unwrap_or(arch==...)` defaults (ON only on those arches), kill switches (`!= Some("0")`, `== "0"`, `_OFF=1`), the `HIPFIRE_AR_GRAPH` resolver, and accessor-level defaults. Excluded: default-OFF flags, numeric and string knobs, and test-only code.
- Arch-conditional rows are ON only on the arch named in parentheses. Rows marked with a qualification default (FA_PREFILL_PM*, MOE_IU4_WIDE_TILES, PREFILL_IU4_*, MOE_ROTATE_I4_PM, GDN_CHUNK_PREP_PM, MQ6_I8, GFX1151_E8_BUFFER) resolve their default in other modules (prefill_route_capabilities, gemm_mq6_i8, DeepSeek4 route), not in this file. Their OFF meaning comes from the field doc comments and consumers; the default was not verified in this sweep.
- Doc-comment alignment: the field doc comments are read from the 12 lines above each field. Some are attached to the wrong neighbor field (e.g. the doc above qwen4_moe_down_r4 describes GDN_LANES_FUSE; the doc above fp16_disabled describes an unrelated PR #616 path). For those rows the OFF text comes from the code and consumers, and the keyword column may be misattributed.
- Mode and tri-state values: `HIPFIRE_QWEN4_HC_FUSE` (level 0-3, per-arch default) and `HIPFIRE_QWEN4_MOE_GLUE_FOLD` (bitmask, all folds when unset) are included as mode. `HIPFIRE_GFX11_WEIGHT_LOAD_POLICY` (default `buffer`) and `HIPFIRE_GFX12_WEIGHT_LOAD_POLICY` (default `rt`) were left out. Their defaults select the incumbent load path and their non-default values are hipcc flags, so they are not new-path defaults. Also excluded: `HIPFIRE_GFX942_LDS_GEMV` (default_on=false), `HIPFIRE_QWEN4_LANE_ALLROWS_EXACT` (default off), and `HIPFIRE_MMQ` (None default).
- OFF-path size: not measured in lines or functions. The consumers columns are reference counts from a grep of the field name, so they include accessor callers and tests. A row with 0 non-test consumers is a deletion candidate only after the consumer list is checked by hand.
- Introduced: first commit in `git log -S'<ENV>' --oneline` (oldest, via `tail -1`). The `-S` search matches the env string, so a rename can point to an earlier commit than the field's introduction. HIPFIRE_G12_A4C2 is a hipcc-flag read with no struct field.
- Not verified in this sweep: whether each OFF path still builds or passes its tests, and whether any flag is set in shipped configs or the process-config schema (hipfire-config). Both are needed before any deletion.
- Zero-hit rows: `HIPFIRE_QWEN4_PREFILL_LWMMA_WAVE_FLOOR`, `HIPFIRE_DDTREE_TOPK_DIRECT_OFF`, and `HIPFIRE_MQ_PROLOGUE_FUSE_OFF` show 0 consumers under the field name, and `HIPFIRE_QWEN4_MOE_SCATTER_SCAN` shows 0 non-test consumers. The first is read through a differently named accessor (`qwen4_prefill_lwmma_floor_knob`), so 0 does not mean dead. Check the other names by hand before treating any of these as unused.
